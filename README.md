# Undergraduate Projects | 학부 프로젝트

**딥러닝 응용 시스템과 공공데이터 분석을 다룬 학부 텀프로젝트 포트폴리오**

모델 학습부터 사용자 인터페이스까지 연결한 감정 인식 프로젝트와, 이질적인 공공데이터를 결합해 지역별 취약도를 비교한 분석 프로젝트를 정리했습니다. 두 작품은 각각 독립적인 텀프로젝트입니다.

| 프로젝트 | 주요 구현 | 기술 | 바로 보기 |
|---|---|---|---|
| **EmotionCare** | 얼굴 검출·4개 표정 클래스 분류·음악 추천·웹 인터페이스 | TensorFlow, YOLO, FastAPI, Streamlit | [프로젝트](emotion-recognition/) |
| **Gyeongnam Heat Vulnerability** | 18개 시군 데이터 통합·순위 기반 점수·등급 지도 | pandas, Matplotlib, Folium | [프로젝트](heat-vulnerability/) |

## Repository Structure

```text
emotion-recognition/    # 학습 코드, 추론 API, 사용자 화면, 설계 문서
heat-vulnerability/     # 분석 노트북, 재계산 스크립트, 집계 결과, 시각화
```

각 프로젝트 문서에서 문제 정의, 데이터 흐름, 구현 결과, 실행 조건을 확인할 수 있습니다. 팀 프로젝트 결과와 개인 담당 범위는 확인 가능한 자료에 맞춰 구분했습니다.
